## Overview

This is a **vanilla JavaScript calculator**. It allows users to perform basic arithmetic operations: **addition, subtraction, multiplication, and division**.
The project demonstrates **unit testing, linting, CI/CD, and code coverage tracking** using GitHub Actions.

## Features

- Simple and responsive **UI** built with HTML, CSS, and vanilla JS
- Arithmetic functions in a separate module (`calculator.js`)
- Unit tests with **Jest**
- Linting with **ESLint** to ensure code quality
- **Continuous Integration** with GitHub Actions
- **Code coverage** reporting and visualization via Codecov
- **Status badges** in README to show build and coverage status

## Technologies Used

- **JavaScript (ES Modules)** – core logic
- **HTML5 & CSS3** – UI and styling
- **Jest** – unit testing framework
- **ESLint** – linting and code style enforcement
- **Node.js** – runtime for tests
- **GitHub Actions** – CI/CD pipeline
- **Codecov** – code coverage tracking
